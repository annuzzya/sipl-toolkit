# Журнал змін

Формат — [Keep a Changelog](https://keepachangelog.com/uk/1.1.0/), версіонування — [SemVer](https://semver.org/lang/uk/).

## [0.1.0] — 2026-11-11

### Додано
- Лексер і парсер SIPL (рекурсивний спуск), типізований AST з позиціями, діагностика `E-LEX-001`, `E-PARSE-001/002/003` (CORE-02).
- Аналіз змінних і визначення вхідних змінних програми (`I-ANA-001`).
- Дерево синтаксичного виводу з AST: text, JSON, DOT, SVG, HTML; нумеровані листки, зв'язок вузлів із фрагментами коду (VIS-01).
- Автоматична побудова семантичного терму за правилами `NS_*` з поясненням кроків; формати unicode / ascii / LaTeX / JSON (SEM-01).
- Обчислення терму на стані за формулами `AF_*`, trace, значення ⊥ (відсутня змінна, ліміт кроків) (SEM-02).
- Асистент доведення: індукція за k (точна символьна арифметика), інваріант і варіант, емпірична перевірка, контрприклади, вердикти proved / bounded / refuted (SEM-04).
- CLI `sipl` з командами check, parse, tree, term, eval, prove; JSON-контракти (`schema_version: 1`); коди завершення 0–5.
- 102 автотести, 8 прикладів, документація українською.
