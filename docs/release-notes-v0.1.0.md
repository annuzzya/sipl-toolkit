# SIPL Language Toolkit v0.1.0

Перший реліз. Трек «Формальна семантика»: CORE-02, VIS-01, SEM-01, SEM-02, SEM-04, REL-02 (разом 10 балів).

**Що всередині:** парсер SIPL, дерево виводу (SVG/DOT/JSON/HTML), семантичні терми за NS_*, обчислення за AF_* з ⊥,
асистент доведення коректності (індукція за k + інваріант, контрприклади), CLI `sipl`.

**Встановлення:** `pip install sipl_toolkit-0.1.0-py3-none-any.whl` (або `pip install .` з вихідників).

**Перевірка:** `sipl eval examples/sum_ap.sipl --state N=3` → `[N ↦ 0, S ↦ 18, T ↦ 9]`.

**Артефакти:** wheel і sdist у `dist/`; контрольні суми — `SHA256SUMS`.

**Відомі обмеження:** один верхній цикл без вкладених у доведеннях; інваріант задає користувач; тільки цілі числа.
