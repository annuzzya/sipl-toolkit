# Граматика й розв'язання неоднозначностей

Вихідна БНФ курсу неоднозначна (наприклад, `a - b - c`, `a + b * c`, `S ; S ; S`, `¬ b ∨ b`).
Парсер реалізує єдину граматику з EBNF у `grammar/sipl.ebnf`; правила вибору такі.

| Питання | Рішення | Приклад |
|---------|---------|---------|
| `*` проти `+`, `-` | `*` пріоритетніше | `1 + 2 * 3` = `1 + (2 * 3)` |
| `+`, `-` | ліво-асоціативні | `10 - 3 - 2` = `(10 - 3) - 2` |
| `¬` проти `∨` | `¬` пріоритетніше | `¬a > 0 ∨ b = 1` = `(¬(a>0)) ∨ (b=1)` |
| `∨` | ліво-асоціативний | |
| `;` | ліво-асоціативна за замовчуванням, `--seq-assoc right` дає праву | `a; b; c` = `(a; b); c` |
| тіла `if` / `while` | один оператор; складений — у `begin … end` | `while x>0 do x:=x-1; y:=1` = `(while …); y:=1` |
| дужки | `(x) > 0` — арифметична дужка; `(x > 0)` — булева дужка (вузол `ParenB`) | |

Чому `;` ліво-асоціативна: так побудовано терми в підручнику (`AS^S(0̄) · AS^T(0̄) · WH(…)` — композиція зліва направо);
результат обчислення не залежить від вибору, але форма дерева — залежить, тому опція винесена в CLI.

Слова `or`, `not` — синоніми `∨`, `¬`. Ключові слова (`begin end if then else while do skip`) не можуть бути іменами змінних.

## Коди діагностики

| Код | Коли |
|-----|------|
| `E-LEX-001` | невідомий символ або число, що зливається з літерами (`12ab`) |
| `E-PARSE-001` | несподівана лексема; повідомлення каже, що очікувалось |
| `E-PARSE-002` | несподіваний кінець файлу (немає `end`, порожній файл) |
| `E-PARSE-003` | зайвий текст після кінцевого `end` |
| `I-ANA-001` | інформація: змінна читається до присвоювання — вхідна |
