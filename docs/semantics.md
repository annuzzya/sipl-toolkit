# Семантика: відповідність курсу

## Терми
| Запис | Клас у `term.py` | Значення |
|-------|------------------|----------|
| `n̄` | `ConstT` | константна функція зі значенням n |
| `x⇒` | `DenomT` | функція-денотат: стан ↦ значення змінної x (⊥, якщо x не визначена) |
| `Sⁿ(f, g₁…gₙ)` | `SupT` | суперпозиція: `Sⁿ(f, g₁…gₙ)(st) = f(g₁(st), …, gₙ(st))`; `f` — `add sub mult gr eq or neg` |
| `ASˣ(f)` | `AssignT` | `ASˣ(f)(st) = st ∇ [x ↦ f(st)]` |
| `f · g` | `SeqT` | `(f · g)(st) = g(f(st))` — послідовне виконання |
| `IF(p, f, g)` | `IfT` | гілка за `p(st)` |
| `WH(p, f)` | `WhileT` | цикл доки `p(st)` істинне |
| `id` | `IdT` | тотожна функція (для `skip`) |

## Правила побудови (`build.py`)
`NS_Prog` (зняти `begin … end`), `NS_Stm_As`, `NS_Stm_Seq`, `NS_Stm_If`, `NS_Stm_Wh`, `NS_Stm_BE` (зняти `begin … end`),
`NS_Stm_skip`, `NS_A_Num`, `NS_A_Var`, `NS_A_Add`, `NS_A_Sub`, `NS_A_Mult`, `NS_A_Par`, `NS_B_gr`, `NS_B_eq`, `NS_B_or`,
`NS_B_neg`, `NS_B_Par`. `sipl term --explain` друкує кожен застосований крок у вигляді `NS_…: sem_X(…) = …` з позицією у коді.

## Формули обчислення (`evaluate.py`)
`AF_AS` (присвоювання), `AF_SEQ` (послідовність), `AF_IF`, `AF_WH` (кожна перевірка умови — «голова циклу» з номером k і станом `st_k`),
`AF_ID`. Значення ⊥ (клас `Undefined`) виникає, коли:
1. читається змінна, якої немає в стані (`E-EVAL-UNDEF`);
2. перевищено ліміт кроків — цикл імовірно нескінченний (`E-EVAL-LIMIT`).
⊥ поширюється: якщо підтерм не визначений, то весь терм не визначений. У гілці `if`, що не вибрана, змінні не читаються.

## Стан
`State` — незмінний словник. `st ∇ [x ↦ v]` повертає **новий** стан: у ньому x має значення v, решта — як у st.
Стани друкуються як `[N ↦ 0, S ↦ 18, T ↦ 9]`; задаються як `"N=3"`, `"X=5, Y=2"` або `"[N ↦ 3]"`.

## Приклад (варіант 18)
Програма: `S:=0; T:=0; while N>0 do begin T:=T+3; S:=S+T; N:=N-1 end`.
Терм: `AS^S(0̄) · AS^T(0̄) · WH(S²(gr, N⇒, 0̄), AS^T(S²(add, T⇒, 3̄)) · AS^S(S²(add, S⇒, T⇒)) · AS^N(S²(sub, N⇒, 1̄)))`.
На `[N ↦ 3]`: стани на початку ітерацій `st₀=[3,0,0]`, `st₁=[2,3,3]`, `st₂=[1,9,6]`, `st₃=[0,18,9]` (N,S,T) — цикл зупиняється.
