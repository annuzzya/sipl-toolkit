# Асистент доведення коректності

## Вхід
Програма однієї форми: `init-оператори ; while B do тіло ; (завершальні оператори)`; специфікація — JSON (див. json-contracts).
Асистент **перевіряє** подані користувачем формулу стану `st_k` і/або інваріант; сам їх не вигадує.

## Режим А — індукція за кількістю ітерацій k (точно)
Користувач задає `closed_form`: значення кожної змінної в стані `st_k` після k ітерацій, і `iterations` — кількість ітерацій K.
Усі вирази — многочлени від параметрів і k з раціональними коефіцієнтами (`poly.py`).

| Крок | Що перевіряється |
|------|------------------|
| A0 | початковий стан `st` із `inputs`, передумова |
| A1 | символьне виконання ініціалізації → `st₀` |
| A2 | база: `st₀(v)` = формула при k=0 для всіх v |
| A3 | крок: символьно виконати тіло на `st_k`, порівняти з формулою при k+1 (тотожність многочленів) |
| A4 | умова циклу: істинна при 0 ≤ k < K (аналіз знаків коефіцієнтів у k = K−1−j), хибна при k = K → завершуваність і кількість ітерацій |
| A5 | післяумова на `st_K`: обидві частини рівності збігаються як многочлени |

Змінні, яких цикл не змінює, вважаються сталими (`st_k = st₀`). Якщо A2–A5 точні й успішні — вердикт **proved** (для всіх значень параметрів).

## Режим Б — інваріант і варіант (обмежена область)
Перевіряються на всіх станах області `0..domain` (за замовчуванням 8, залежить від кількості змінних) через **справжнє обчислення семантичних термів**:
B1 `pre ⇒ I` після ініціалізації; B2 `I ∧ B ⇒ I` після тіла; B3 `I ∧ ¬B ⇒ post`; B4 `I ⇒ V ≥ 0`; B5 `I ∧ B ⇒ V' < V`.
Успіх дає **bounded**: контрприкладів немає, але це не доведення.

## Режим Е — емпірична перевірка
Програма виконується на вхідних станах області; на початку кожної ітерації перевіряються інваріант і формула `st_k`, у кінці — післяумова й кількість ітерацій.

## Вердикти й коди
| Вердикт | Код | Умова |
|---------|----:|-------|
| proved | 0 | усі A-кроки точні та успішні |
| bounded | 5 | немає контрприкладів, але частина перевірок лише на області (або символьно не вдалось) |
| refuted | 4 | будь-який крок «ПОРУШЕНО»; є контрприклад (значення параметрів, кінцевий стан, різниця) |

Повна коректність = часткова коректність (post) + завершуваність (варіант / лічильник A4). Обидві частини явно показані у звіті.

## Межі
Один верхній цикл без вкладених; присвоювання з `+ - *` і діленням на сталу; умова — порівняння `=`, `>`; контрприклади для нелінійної умови шукаються лише на області. Усе це виводиться у звіті в розділі «Межі асистента».
